# 🛒 CartPilot AI

CartPilot AI is an autonomous sales and checkout agent designed for D2C e-commerce.

It helps users overcome decision fatigue by understanding their shopping intent, recommending relevant products, answering common purchase doubts, and guiding them toward checkout.

## 🚀 Features

### 🧠 Intent & Catalog Matching

CartPilot understands user requests and searches the merchant product catalog to recommend the top matching products.

Example:

> "Running shoes under ₹3,000"

### 💬 Buyer Hesitation Handling

CartPilot can answer common buyer questions related to:

- Product sizing
- Returns and exchanges
- Cash on Delivery
- Payment safety
- Shipping and delivery
- EMI and offers

### 🛍️ Product Recommendations

The agent limits recommendations to the top 2 products to reduce decision fatigue.

Each recommendation includes:

- Product name
- Price
- Rating
- Product description
- Key differentiators

### ⚡ Checkout Flow

Users can select a product and move to a demo checkout experience.

The project simulates:

- Quick checkout
- UPI checkout
- Cash on Delivery

⚠️ No real payments are processed.
